All logo files contain vector paths, not embedded raster images. The full-colour HKU SVG
has an added `viewBox="0 0 208 40"` matching its original dimensions for
responsive scaling. Its paths and colors are unchanged.

The displayed monochrome HKU logo uses the official footer's white vector line
art, with `#fff` changed to `#000` for the site's white background, and an added
`viewBox="0 0 276 54"` matching the original dimensions. All path data are
unchanged. This is a black rendering of the official reversed monochrome
artwork, not an independently downloaded black master or a grayscale conversion
of the full-colour shield.

HKU's [basic specifications](https://www.hku.hk/en/about-hku/university-identity/basic-specifications)
illustrate a black horizontal monotone version and state that monotone versions
should be used when full colour is unsuitable. The full shield/wordmark download
requires HKU Portal login. This source record does not confer brand-use approval.
CSS scales each logo proportionally without cropping or stretching it.
